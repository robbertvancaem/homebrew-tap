# homebrew-tap

Personal Homebrew tap by [@robbertvancaem](https://github.com/robbertvancaem).

## Usage

```bash
brew install robbertvancaem/tap/<formula>
```

Or tap once and install by short name:

```bash
brew tap robbertvancaem/tap
brew install <formula>
```

## Available casks

| Cask | Description |
|------|-------------|
| [`claude-status-bar`](https://github.com/robbertvancaem/claude-status-bar) | Native macOS menu bar app that shows live Claude service status. |
