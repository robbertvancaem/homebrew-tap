# homebrew-tap

Personal Homebrew tap by [@robbertvancaem](https://github.com/robbertvancaem).

## Usage

```bash
brew install robbertvancaem/tap/<formula>
```

Or tap once and install by short name:

```bash
brew tap robbertvancaem/tap
brew install <formula>
```

## Available casks

| Cask | Description |
|------|-------------|
| [`statuspage-menu-bar`](https://github.com/robbertvancaem/statuspage-menu-bar) | Native macOS menu bar app that shows live status of Claude, Kinsta, GitHub or any Atlassian Statuspage page. Formerly `claude-status-bar`. |
